## 📌 Project Description

**The Shadow Front** is a fictional terrorist organization created
for an educational web-development project.

The website demonstrates how HTML, CSS and JavaScript can be used to
create a modern information website while discussing the social,
human and economic consequences of terrorism.

> ⚠️ This is a fictional organization.
> The project does not support terrorism, violence, recruitment,
> extremist propaganda or any real terrorist organization.
